2. ¿Qué diferencias notaste entre usar un controlador autogenerado y uno con repository? ¿Qué enfoque prefieres? 
La diferencia principal es que el controlador autogenerado es más rápido y sencillo, porque tiene 
todo lo necesario para hacer las operaciones básicas. En cambio, el controlador con repository separa 
mejor la lógica y hace que el código sea más ordenado y fácil de mantener.
Preferemimos usar repository, porque permite organizar mejor el proyecto y facilita hacer cambios.

3. ¿Qué buenas prácticas implementaste (en código real) y por qué? 
Implementamos buenas prácticas como separar la lógica usando un repository, mantener el código ordenado 
y usar nombres claros para las variables y métodos. También tratamos de evitar repetir código. 
Lo hicimos porque así el proyecto es más fácil de entender, mantener y modificar cuando sea necesario.
